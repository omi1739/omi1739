## 📌 Featured Projects

### 1. 🏥 Doctor Appointment System
A modern web application for booking and managing doctor appointments with an intuitive interface and seamless user experience.

**Live:** https://doc-appoinment-coral.vercel.app/

**Tech Stack:**
- Next.js 15 | Tailwind CSS 4 | HeroUI
- MongoDB | Better Auth
- TypeScript | Lucide React

**Key Features:**
- Secure user authentication with Google login
- Easy appointment booking and management
- Dark/Light mode support
- Fully responsive design
- Beautiful UI with HeroUI components
- Real-time appointment tracking

**Dependencies:**
```
next, react, better-auth, mongodb, tailwind-css, heroui, lucide-react, next-themes
```

**Get Started:**
```bash
git clone https://github.com/omi1739/doc_appoinment.git
cd doc_appoinment
npm install

# Create .env file with:
MONGODB_URI=your_mongodb_uri
BETTER_AUTH_SECRET=your_secret
BETTER_AUTH_URL=http://localhost:3000
GOOGLE_CLIENT_ID=your_google_id
GOOGLE_CLIENT_SECRET=your_google_secret
NEXT_PUBLIC_API_URL=http://localhost:3000/api

npm run dev
# Open http://localhost:3000
```

**Links:**
- 📂 [Repository](https://github.com/omi1739/doc_appoinment)
- 🌐 [Live Demo](https://doc-appoinment-coral.vercel.app/)

### 2. 🐑 Qurbani Haat
An e-commerce platform for browsing and booking sacrificial animals with a seamless checkout experience and user management system.

**Live:** https://qurbani-haat-ph.vercel.app

**Tech Stack:**
- Next.js | Tailwind CSS | React
- Firebase Authentication | MongoDB
- RESTful API | Axios

**Key Features:**
- Browse available animals with detailed information
- Shopping cart management with persistent storage
- Social login (Google, GitHub) and email authentication
- User profile management
- Real-time toast notifications
- Secure checkout process
- Responsive design for all devices

**Dependencies:**
```
next, react, tailwind-css, firebase, mongodb, axios, react-hot-toast
```

**Get Started:**
```bash
git clone https://github.com/omi1739/Qurbani_Haat.git
cd Qurbani_Haat
npm install

# Add Firebase credentials to .env.local
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
MONGODB_URI=your_mongodb_uri

npm run dev
# Open http://localhost:3000
```

**Links:**
- 📂 [Repository](https://github.com/omi1739/Qurbani_Haat)
- 🌐 [Live Demo](https://qurbani-haat-ph.vercel.app)

### 3. 📚 English Janala
An interactive English vocabulary learning platform with API integration for dynamic content and engaging word learning experience.

**Tech Stack:**
- React | JavaScript | Tailwind CSS
- External API (programming-hero)
- Local Storage

**Key Features:**
- Multiple English proficiency levels
- Interactive vocabulary cards with examples
- Search functionality for quick word lookup
- Save favorite words feature
- Pronunciation guide with text-to-speech
- Responsive mobile-first design
- Persistent storage for saved words

**Dependencies:**
```
react, tailwind-css, axios, react-icons
```

**Get Started:**
```bash
git clone https://github.com/omi1739/English-Janala.git
cd English-Janala
npm install
npm run dev
# Open http://localhost:3000
```

**API Endpoints Used:**
- `GET /api/levels/all` - Get all proficiency levels
- `GET /api/level/{id}` - Get words by level
- `GET /api/word/{id}` - Get word details with examples
- `GET /api/words/all` - Get all available words

**Links:**
- 📂 [Repository](https://github.com/omi1739/English-Janala)
