## 📌 Featured Projects

### 1. 🏥 **Doctor Appointment System**
A modern web application for booking and managing doctor appointments with an intuitive interface.

**Live Link:** [doctor-appointment.vercel.app](https://doc-appointment-demo.vercel.app)

**Tech Stack:**
- Next.js 15 | Tailwind CSS 4 | HeroUI
- MongoDB | Better Auth
- TypeScript

**Key Features:**
- 🔐 Secure user authentication with Google & email login
- 📅 Easy appointment booking and management
- 🌙 Dark/Light mode support
- 📱 Fully responsive design
- 🎨 Beautiful UI with HeroUI components

**Dependencies:** `next`, `react`, `better-auth`, `mongodb`, `tailwind-css`, `heroui`

**Get Started Locally:**
```bash
git clone https://github.com/omi1739/doc_appoinment.git
cd doc_appoinment
npm install
# Create .env file with MongoDB URI and Better Auth credentials
npm run dev
# Open http://localhost:3000
```

**Links:**
- [Repository](https://github.com/omi1739/doc_appoinment)
- [Live Demo](https://doc-appointment-demo.vercel.app)
- [API Documentation](https://github.com/omi1739/doc_appoinment)

### 3. 📚 **English Janala**
An interactive English vocabulary learning platform with API integration for dynamic content management.

**Tech Stack:**
- React | JavaScript
- Tailwind CSS
- External API (programming-hero)

**Key Features:**
- 📖 Multiple English proficiency levels
- 🎯 Interactive vocabulary cards
- 🔍 Search functionality
- ❤️ Save favorite words
- 🔊 Pronunciation guide with text-to-speech
- 📱 Responsive mobile design
- 💾 Local storage for saved words

**Dependencies:** `react`, `tailwind-css`, `axios`

**Get Started Locally:**
```bash
git clone https://github.com/omi1739/English-Janala.git
cd English-Janala
npm install
npm run dev
# Open http://localhost:3000
```

**API Endpoints Used:**
- `GET /api/levels/all` - Get all proficiency levels
- `GET /api/level/{id}` - Get words by level
- `GET /api/word/{id}` - Get word details
- `GET /api/words/all` - Get all words

**Links:**
- [Repository](https://github.com/omi1739/English-Janala)
